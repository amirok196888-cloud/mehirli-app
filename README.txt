V25 — מרכז עבודה מקצועי
=======================
- אזור ייעודי להיינדמן ולחשמלאי בתוך מחירלי.
- קליטת פנייה בטקסט או בדיבור, שאלות הכנה ורשימת ציוד לפי סוג העבודה.
- מחשבון מחיר מינימום ומחיר מומלץ לפי זמן, חומרים, נסיעה והוצאות העסק.
- הצעת מחיר דיגיטלית בקישור, אישור לקוח ושליחה ב-WhatsApp.
- קישור תשלום אישי של בעל המקצוע; הכסף אינו עובר דרך מחירלי.
- תיק עבודה עם תמונות לפני/אחרי, סטטוסים וחישוב רווח בפועל.
- נדרש להריץ פעם אחת את v25-professional-workspace.sql ב-Supabase.

V27 — אפליקציה חד־צדדית לבעל העסק
==================================
- אין הרשמה או אזור אישי ללקוח.
- בעל העסק הוא המשתמש היחיד שנרשם ונכנס לאפליקציה.
- הלקוח מקבל ב-WhatsApp קישור ציבורי להצעה, ללא חשבון וללא התקנה.
- הלקוח יכול לצפות בהצעה, לאשר אותה ולעבור לקישור התשלום של בעל העסק.

V28 — ניהול כל הקטגוריות
=========================
- מרכז העבודה תומך בהיינדמן, חשמלאי, שירותי בית ומיזוג.
- לכל תחום סוגי עבודות, שאלות הכנה ורשימת ציוד מתאימים.
- מנהל מחירלי רואה במסך אחד את כל העבודות ואת כל בעלי העסקים, עם סינון לפי תחום.
- חשבון המנהל נשמר כמנהל ואינו מומר אוטומטית לחשבון בעל מקצוע.

V30 — WhatsApp ותשלום אופציונלי
================================
- בעל העסק שולח את ההצעה ללקוח בלחיצה דרך WhatsApp.
- בהצעה הציבורית מופיע כפתור WhatsApp לבעל העסק אם הוגדר מספר עסקי.
- כפתור תשלום מופיע לאחר אישור ההצעה רק אם בעל העסק הגדיר קישור תשלום.
- קישור התשלום מתאים למקדמה או לתשלום מלא ונכנס ישירות לחשבון הסליקה של העסק.
